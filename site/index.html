NeuroQC

An optimization layer around EEGLAB. It works on the dataset that is current in EEGLAB, reads its real EEG.history, runs every legal combination of the steps you leave open, checks each against a known signal, and tells you which result measures your component most precisely — and which ones the data cannot tell apart from it.

Why NeuroQC?

Preprocessing choices multiply fast, and most labs fix one pipeline by hand. Ranking pipelines by a noise metric alone rewards whatever removes the most — including the effect. NeuroQC searches only what you leave open, prices every candidate by how precisely it measures your component, and rejects candidates that distort a known signal.

🔗 Bound to EEGLAB

No load step. NeuroQC reads the current dataset and its EEG.history, opens native EEGLAB dialogs, and records every command it runs. Adopted candidates become EEGLAB datasets whose history reproduces them.

🔍 Exhaustive where you want it

Fix any step, order or value; everything else is enumerated, with illegal orders explained rather than rearranged. Shared prefixes run once. Large spaces can be sampled — and are then labelled approximate.

🧪 Known-signal checks

Filters are checked with a probe through the same EEGLAB calls; data-driven steps with a known signal carried through every candidate under the same channel, ICA and rejection decisions.

📏 Your measure, your units

Mean amplitude, peak amplitude, peak latency or band power. Data quality is the standardized measurement error of that measure, so the trial-loss trade-off is priced in.

⚖️ Honest uncertainty

A paired bootstrap over the same trials says which candidates the data cannot distinguish from the best. That is not equivalence — equivalence needs a margin you set.

♻️ Reproducible and resumable

Every candidate carries its EEGLAB commands; searches checkpoint per candidate and resume to the same result. Independent branches can run in parallel.

How it works

From the dataset you have open to a recommendation you can adopt.

1

State

Current dataset and parsed history, each item labelled by provenance; inconsistencies are reported, not guessed.

2

Plan

Steps in order; single values fixed, {a, b} searched, alternatives or “none” per position, native EEGLAB commands as fixed steps.

3

Search

Every legal pipeline on copies, printed command by command, with constraints and signal checks per candidate.

4

Adopt

The recommended (or any) candidate becomes a new EEGLAB dataset, re-run and checked to give the same scores.

Getting started

git clone https://github.com/abwoo/NeuroQC.git
% in MATLAB, with EEGLAB on the path:
addpath('NeuroQC'); neuroqc_setup     % EEGLAB > Tools > NeuroQC

⚙️ Requirements

MATLAB R2021b or later, EEGLAB with firfilt. ICLabel for IC removal, clean_rawdata for ASR, Parallel Computing Toolbox optional.

⚠️ Limitations

The analysis contract (events, windows, ROIs) is never searched. A passed signal check is necessary, not sufficient. See the README before trusting a result.

Questions, answered

  • Is this an AI / LLM tool? No. Enumeration, EEGLAB processing and resampling statistics. No model, no API key, no telemetry, no network access.
  • Where is my data sent? Nowhere. Everything runs locally in MATLAB, and the dataset you have open is never modified during a search.
  • Does it pick my reference or my windows? No. Those define what is measured. Different references can be compared, but each is ranked in its own stratum.
  • Can I use it on my data today? Yes — MIT licensed, no warranty.
