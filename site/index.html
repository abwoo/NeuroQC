Why NeuroQC?

EEG preprocessing is a discrete combination problem: filters, epoch windows, artifact rules, ICA policies, re-referencing — each with a handful of defensible values, multiplying fast. Most workflows fix one pipeline by hand. NeuroQC searches the space exhaustively, ranks it by your goal, and keeps every result reproducible.

🎯 Goal-driven ranking

Pareto front plus a weighted GoalRanker. Change the profile — Balanced, Retain more trials, Lower filter distortion, Stable topography — and the ranking updates with no re-search.

🔍 Exhaustive discrete search

Full combination enumeration with legality constraints, order search (fixed / free / slot-locked) and a budget guard that refuses silently-truncated sampling.

🩺 QC in the loop

Import QC metrics (CSV/JSON) you already measure in EEGLAB. GoalScore and labels only ever reflect evaluated candidates — nothing is invented.

🛡️ Config-drift gate

Edit any setting after generating recipes and Results actions lock behind a red Required: Settings changed… hint. Stale recipes can never meet new settings.

📜 Reproducible recipes

Every candidate becomes a standalone recipe_E000001.m script with its exact parameters — rerun it or hand it to a collaborator.

🧩 Contracts & handoff

Events, windows and components-of-interest declared once and validated fail-closed; resume from checkpoints and lock step order absolutely.

Manual vs NeuroQC on this exact run: by hand you would settle on one filter pair, maybe try a second — 1–2 pipelines with no record of what was skipped. NeuroQC enumerated all 8, executed all 8 on copies, kept the Pareto-optimal 6, and returned a ranked shortlist where every row is a reproducible script.

How it works

Four tabs, one contract, one search, one ranked shortlist.

1

Data

Load the EEG snapshot; set data unit, QC file path and trial rule.

2

Scope

Choose steps and their order, handoff stage, analysis contract and ranking profile.

3

Params

Declare discrete candidate values per step; preview the search-space grid before anything runs.

4

Results

Recipes, Pareto front, GoalScore, QC import, compare, gated retry — locked by the drift gate on any edit.

Questions, answered

  • Is this an AI / LLM tool? No. Exhaustive enumeration, Pareto filtering, weighted ranking. No model, no API key, no telemetry, no network access — “copilot” only means interactive goal refinement.
  • Where is my data sent? Nowhere. Everything runs locally in MATLAB; recipes and reports land in folders you choose.
  • Can I use it on my data today? Yes — MIT licensed, no warranty. Copy the repo into eeglab/plugins/ and follow the Getting started section.
  • Do I need EEGLAB? The wizard runs inside EEGLAB; the headless API path works in plain MATLAB with EEGLAB on the path.
